# Cowart P0 图片交互验收记录

日期：2026-10-19。关联 Issue #24 / #23；任务分支 `codex/24-canvas-interactions`，基于集成提交 `0559e06`。精确提交和 CI 链接以任务 PR 为准。

## 实现

复用 tldraw 选择、框选、平移和右键菜单。扩展图片双击为原图预览，裁剪仍可从原有图片工具栏进入。单选真实图片后，图片下方提供「预览原图」「修改这张图」，避开 tldraw 原生图片工具栏；修改操作只打开 Studio 聊天并聚焦输入框，不自动调用模型。

预览读取原始资产地址，保持比例；点击图片不关闭，点击图片以外区域或 Escape 关闭。预览期间焦点留在对话框内、快捷键不穿透画布，关闭后恢复焦点。既有侧栏和图片数据保持原样。

## 本机真实 Chromium 验证

| 项目 | 结果 |
| --- | --- |
| 单击图片 | 仅选中，不打开预览 |
| 双击未选中或已选中图片 | 打开原图，不进入裁剪；加载真实像素尺寸 |
| 点击预览图 / 外部点击 / Escape | 图片点击保持打开；外部点击及 Escape 正常关闭 |
| Tab 与关闭焦点 | 焦点留在预览内，底层工具不响应 |
| 就地修改入口 | 侧栏关闭时可重新打开并聚焦自然语言输入框，不发起生图 |
| 输入空格、Delete | 文本编辑正常，不平移画布、不删除选中图片 |
| 图片上空格 + 左键拖动 | 只平移；松开恢复选择工具，图片坐标不变 |
| 图片上中键拖动 | 平移画布，图片坐标不变 |
| 空白处左键拖动 | 框选范围内图片，范围外图片不选中 |
| 图片右键 | 原生上下文菜单可用，不误开预览 |
| 保存与刷新 | 两张原图均保留，交互不修改或覆盖图片 |

测试使用本地 PNG 夹具和真实 gateway 鉴权/项目/快照服务，无付费模型调用。脚本为 `cowart/tests/canvas-interactions.mjs`，由既有浏览器冒烟测试调用；截图随 CI 工件保存。

本分支全量 `npm test` 为 161 项通过；Cowart 构建、完整 Chromium 冒烟通过。PR #26 是独立的任务恢复改动，未以它的 162 项测试替代本分支验证。
