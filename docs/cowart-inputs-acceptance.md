# Cowart P0 Holder 与多图参考验收

日期：2026-10-19。关联 Issue #24 / #23。分支 `codex/24-holder-reference-inputs`，基于集成提交 `0559e06`；精确提交与 CI 以任务 PR 为准。

## 实现

- 选区监听等待 tldraw 编辑器就绪，选择图片或 Holder、修改尺寸后同步比例；画布未就绪时不提前回填任务结果。
- 空 Holder 可直接接收生成结果。比例下拉可调整空框，图片等比容纳；有图片、分组或标注等内容的 Holder 不再覆盖或改尺寸，新图放旁边。结果与原图保持实际像素比例。
- 单图默认作为修改对象；多图或 Holder 默认综合参考。用户可明确一张主图，其他图片分别设为综合、造型结构、配色、风格材质、动作构图、背景氛围。
- 单张参考的高级选项默认折叠，多图时展开；自然语言仍是主要入口。智能规划若只有一张源图和一个空框，可自动确定唯一修改对象。
- 已有生成图通过受当前账号/项目校验的历史 ID 复用，不再次上传。导入图逐张导出，角色与图片一一对应；导入图编辑走编辑能力配置，主图在实际模型输入中排第一。
- 混合导入图与历史图时保留选定顺序；主图移到实际输入首位后，会明确说明画布编号与实际输入的对应，避免“第三张主图、第一张配色”被解释错。重复、越界或缺失的顺序在调用模型前拒绝。
- 已确认的项目风格图若已经作为本轮参考，会按历史图片身份去重，保留本轮明确选择的角色，避免同一张图再次以风格角色加入而产生冲突。
- 复用原队列、适配器和角色提示；无新增用户、计费系统。文字规划接收角色标签，视觉规划目前只看主图或首张参考，图片模型接收全部参考，不冒充全量视觉理解。

## 已验证

- 本分支全量 `npm test`：164 项通过；Cowart 构建通过，原有 bundle 提示仍在。
- 后端实际适配器 + 模拟图片上游：逐图角色到达请求，综合参考不被当作修改源；原始主图字节排第一，独立编辑路由生效；无效角色、数量超限、跨账号历史图片在调用上游前被拒绝。
- Chromium：既有一张生成 + 两轮编辑链路三次提交；新增五次输入用例为：空 Holder 与双参考综合生成、第三张主图加第一张配色/第二张风格、非空 Holder 新图放旁边、导入图编辑、智能规划下单图加空框。累计八次图片提交。
- 空框等比容纳模型返回的方形测试图，不拉伸为竖图；非空框在新任务切换比例时尺寸不变。参考原图坐标不变，Holder 子图保存和刷新后保留。
- 截图 `canvas-inputs.png` 随 CI 工件保存。本地图片/规划接口为模拟，账号、项目和快照为真实 gateway 服务。
