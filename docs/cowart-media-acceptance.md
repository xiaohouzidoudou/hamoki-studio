# Cowart 已保存画布的媒体保护

关联 Issue #24。本项保护容量回收过程中的原图，尚未实现图片拆分上传，也不提高快照大小上限。

## 行为

- 同账号的所有落盘 Cowart 画布引用的 `/api/media/<uuid>.png|jpg|webp` 原图，不进入自动清理候选。生成图和导入图按实际文件引用保护，不依赖旧 Studio 节点是否存在。
- 每次需要回收空间时重新读取快照，包含其他标签页新保存的引用。归档画布也保守保留；只有成功保存移除引用，或按既有流程移除相应快照后才解除保护。
- 无足够可回收空间时返回 413。不会为了新上传删除已保存画布所用原图；未引用旧图仍遵循既有容量回收规则，缩略图仍可回收。
- 快照不可读取、JSON 损坏或结构无法识别时返回 503，并在删除任何缩略图或原图之前停止自动清理。普通读取与有足够空间的上传不受这一检查影响。
- 仅检查当前账号的数据目录，不扩大图片读取权限，也不读取其他账号的快照。

## 验证

- 真实临时网关与两个账号，模拟约 3MB 全局容量：上传 1.5MB 原图并保存引用，再上传 1.8MB 图片。修复前错误返回 201；修复后返回 413，原图及快照仍可读，其他账号读图为 404。
- 成功保存移除引用后，再次上传同大小图片返回 201，原来未引用图片被按既有规则清理。
- 单元回归覆盖多快照引用合集、重复引用、外部 URL、路径穿越、损坏 JSON 与缺失 store；异常时拒绝回收。
- 本分支全量 163 项测试、Cowart 构建通过。精确 SHA 和 CI 结果在任务 PR/Issue 更新。

本项未部署、未调用真实模型，不证明真实模型效果、计费或跨设备端到端通过。后续仍需媒体拆分上传、保存并发修复集成、授权模型与完整隔离 QA 验收。
