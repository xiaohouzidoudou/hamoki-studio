# Cowart 图片拆分上传验收

关联 Issue #24。此项让图片字节独立保存，避免多张图片内嵌为 base64 后超过画布快照的 12MB 上限。快照原有大小和记录数量限制保持不变。

## 存储与失败行为

- `POST /api/cowart/assets?projectId=<id>` 接收 PNG/JPEG/WebP 原始字节；需要开启 Cowart、已登录、同源请求以及属于当前账号的有效项目。读取请求体后再次校验项目。
- 单图最多 12MB，复用现有图片内容校验。当前账号媒体目录保存原图，继续通过已有账号鉴权媒体接口读取，不创建旧 Studio 画布节点。
- 按图片内容 SHA-256 在当前账号内去重，重复请求和服务重启复用同一 URL；不同账号不会共享图片路径。账号图片索引最多 4096 项，坏索引或不一致媒体拒绝继续写入。
- 同步检查账号与全局剩余容量，包含原图和索引增量；不足直接返回 413，不调用旧的自动删图流程。文件/索引写入失败只清理本次新文件，保留已有媒体。
- blob/data 图片逐张上传，同一保存中的相同 source 仅上传一次。上传失败不提交部分快照，画布原始图片保留。上传成功但快照保存失败时图片会保留，下一次请求去重，不重复占用图片空间。
- 快照成功后，只有 live asset 的 source 仍与捕获值相同时才更新为 URL；保留尺寸和其他属性，删除/替换中的资产不被复活或覆盖。后续移动图片无需重新上传。
- 暂不自动清除上传后尚未写入成功快照的图片，防止破坏重试或并发保存。这部分占用仍受配额和索引数量限制，需要后续统一素材生命周期管理。

## 已验证

- 本分支 166 项测试、Cowart 构建、协作规范与 diff 检查通过。精确提交及 CI 以任务 PR/Issue 为准。
- 临时真实网关：匿名/跨账号项目/跨站上传拒绝、MIME 和内容不符拒绝、单图超限拒绝、账号和全局分别超额拒绝；旧图仍可读，没有额外文件。
- 同图重复上传、服务重启、双账号媒体读取隔离、缺失去重文件重建、损坏索引拒绝、模拟索引落盘失败不留本次新文件。
- Chromium：两张各 5MB 的内嵌 PNG 让原快照超过 12MB。第一次上传模拟 503，快照不提交、原图 source 不变；编辑触发重试后两图上传成功，快照小于 100KB。真实媒体接口各返回完整 5MB；移动并刷新后位置与图片引用保留，不再上传原图字节。最终截图已检查，CI 工件保留截图。
- 真实 tldraw 校验曾发现仅更新 `props.src` 会丢失尺寸；已修复为保留完整属性，并补尺寸保留回归。并发替换/删除的旧响应不覆盖新图片。
- 既有模拟生成、连续两轮编辑、原图保留、失败保存恢复和三次任务提交回归通过。

## 集成与 QA

本项未部署、未调用真实付费模型。需要合入保存版本修复 PR #29 和原图保护 PR #30 后进行组合回归；本项不替代它们的保存竞态与清理保护。其余待审任务恢复、图片交互和参考输入 PR 也需完整集成验证。

隔离 QA 验收：核对实际提交 SHA，导入多张图片，检查上传失败提示、保存与刷新、只移动时不再上传、容量不足保留旧图，并验证跨设备读取。真实图片参考/模型任务请求仍有独立体积和输入数量限制，不能由本项推定全部大图模型场景通过。

回滚：撤销代码无需转换图片或快照；既有媒体读取接口仍可读取已经保存的 URL。保留账号媒体与索引，不重置数据卷。
