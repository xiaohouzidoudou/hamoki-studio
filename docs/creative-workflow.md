# Hamoki Studio 游戏 UI 多 AI 美术工作流（测试版）

本功能附加于现有 Hamoki Studio，保留原无限画布、项目、登录和图片模型队列。

## 使用方式

1. 左侧打开「AI 美术工作流」，连续或批量上传 Word DOCX，单份最多 12MB，最多 12 份；重复文件按 SHA256 拒绝。Word 文字、表格、章节、原型图会提取到当前账号项目，不覆盖已有文档，上传不会扣除 AI 额度。
2. 免费按标题和图文顺序建立页面任务，缺原型会显示待补充。也可以点击「AI 智能拆页」调用一次文字模型，按文档真实出现的页面名称重新归纳，需人工确认模型费用。
3. 页面清单按页选择和编辑要求，原型图片只能选该页文档里的图片，不自动错配。不同页面保留各自的提示词和视觉质检结果。
4. 在画布选择 0–5 张真实游戏 UI 风格图；AI 分析后保存为整个项目的 Style DNA，可以锁定并让后续页面复用。更换风格图会要求确认清空旧风格与旧设计方案。**本项目的模型选择分成文字、视觉、生图三个独立服务商 + 模型下拉菜单**。点击「获取模型」调用各自能力的 `/models`；如果服务商不开放列表，可以选择「手动输入」填模型 ID。点击「保存模型选择」单独保存到本项目；没有指定文字/视觉模型时，分析开始之前明确报错，不会假启动。
5. 文字模型可选 GPT/DeepSeek 等，视觉模型必须真正支持看图。点击「分析当前页面」或「批量完成缺失页面方案（最多 8 页）」时，再人工确认可能的付费调用。风格识图、原型分析、美术总监按步骤执行并保存到所选页面；没有原型图则标注不确定性。
6. 点击「送入画布生图操作台」，当前页的文字方案、风格图和原型图分别带到原操作台。图片生成由用户自行选择 GPT Image 2.5 或 Gemini 香蕉，点击生成才调用付费图片模型。
7. 生成结束后可以对照风格、原型、输出图做视觉质检，返回返工建议；没有自动无限重试，最终由用户审核。

## 限制与安全

- 目前 Word 包含图文，但不自动 OCR 扫描图；复杂图表、跨文档关联、模型风格保真度需要真人审核。
- 原型缺失的页面只按文字分析，不能声称布局已还原。AI 智能拆页名称必须与原文匹配，不得虚构内容。
- 每个账号的数据隔离，源图与 Style DNA 属于项目数据；项目备份可带走多文档页面状态并重映射素材 ID，不包含账号密钥或模型路由。
- 模型调用仅在人工点击并确认后触发，超时、服务重启不会自动重复付费。图片模型继续复用原工作台。
- 已正式引入并在运行时读取固定版本的 [tnbao91/ai_asset](https://github.com/tnbao91/ai_asset) 上游 STYLE、ASSET、CHECK、官方 Schema、风格词典及 [game-ui-design-workflow](https://github.com/guiguiyan930-source/game-ui-design-workflow) 原始设计 Skill；见 `vendor/UPSTREAM.md` 的版本、许可证和详细调用说明。STYLE 产出的 YAML 必须通过原 Schema 类型/枚举验证，不合格明确失败，不冒充已批准的风格。用户需核对颜色并手动锁定。无 Unity、切图、图集输出。
- 测试使用独立开发分支和预览环境，正式站不变。真实策划文档与任何 API Key 不上传公开仓库。

## 新增开源游戏 UI 技能（固定原始版本）
- game-ui-ux：布局分析时检查安全区、比例和长文本；质检中检查可见文字、按钮边距。
- threejs-game-ui-designer：美术总监加强活动/菜单的视觉主次、个性化组件造型、游戏世界观一致性；避免普通网页后台式排版。
- 只提取适用于静态游戏 UI 图片的原文段落，不会自动编写 Three.js/Unity 运行时、交互事件和图集切片。
- Style DNA 和策划 Word 优先；原型只提供功能元件及布局，不提供美术风格。禁止擅自新增奖励或功能。
- 原始来源、许可和固定提交见 vendor/UPSTREAM.md。

## 一图衍生素材（无需 Word）
1. 打开左侧「一图衍生素材」，直接从当前项目画布选择 1–5 张游戏画风图；如果当前项目原有 AI 工作流已保存 Style DNA，可在下拉选项中免费复用。
2. 没有 Style DNA 时，先选择支持看图的视觉模型，点「分析选中参考图」，人工确认可能的视觉模型费用。新结果仅保存在独立素材工作台，**不会覆盖原 Word 工作流和已完成的页面设计方案**。
3. 在「素材任务清单」修改五种默认类型（游戏 UI 界面 / UI Kit / 图标道具 / 游戏背景 / 角色设定），可增删，最多 8 项。点击「按 ai_asset 自动准备多份提示词」会明确确认文字模型费用，使用官方 §4 SYNTHESIZER + 四类原始 schema + 项目 Style DNA，一次生成多个**可修改**的草稿；不调用生图模型。
4. 审核并编辑每条提示词与生成比例，点击「保存提示词修改」可以无费用持久保存。可多选所需草稿，选择生图服务商、模型、分辨率，点击「确认费用并批量生图」后才一次性送进原有排队系统。每个草稿只允许提交一次，不会自动付费重试，也不会悄悄创建额外任务。
5. 完成后的图像出现在当前项目画布及原图库；UI Kit / 图标 ASSET SHEET 是**一张整图素材板**，不是切好的独立文件。角色姿势身份锁定需要专门角色参考图；此第一版不实现动画、Unity 导出或切图。
6. 单一请求已执行但模型/网络报超时不代表上游没有计费，请先核实账单再决定是否重试。
