HAMOKI STUDIO GUIDE

使用帮助

从第一次注册到 AI 生图与画布整理，几分钟就能上手。

三步开始创作

01创建自己的账号

输入用户名、密码和邀请码；每个账号有独立的项目和 API Key。

02配置一个 AI 服务商

填写 API 地址与自己的 Key，保存前即可测试连接、获取模型。

03输入描述，开始生成

选择模型、尺寸和数量，确认请求后等待作品出现在画布上。

账号注册与登录

点击「注册」，填写用户名、密码和同事提供的邀请码；注册完成后即可进入独立工作区。以后在任何设备使用同一个账号登录，就能看到自己的项目和中转站。

本站不绑定邮箱，也没有密码找回服务，请保管好密码。不同账号的作品、历史和 API Key 不会互相共享。

添加中转站与选择模型
  1. 打开左侧「中转站管理」→「添加中转站」。
  2. 填写名称、API Base URL（OpenAI 兼容接口通常以 /v1 结尾）及自己的 API Key；按服务商实际接口选好协议与生图模式。
  3. 填写 API 地址及 Key 后可立即测试连接、获取模型，选择各能力的模型 ID 后再保存中转站。
  4. 在助手底部点击左侧中转站名称切换服务商；再点击右侧生图模型框或下拉箭头，自动获取当前服务商的可用模型，输入关键词搜索，点选即可用于下一次生图。仍支持手动输入模型 ID。
  5. 模型选择以本次操作台选择为准，无需保存默认能力路由。获取到模型列表不代表模型一定支持生图；必要时使用「试生成1张」确认（可能产生费用）。

注意：不要把 /images/generations 等具体请求路径填到 API Base URL。API Key 会在你自己的服务端工作区加密保存。

连续 AI 文字对话

在助手底部切换「文字对话」，选择服务商和本次文字模型后即可发送，无需保存默认能力路由。同一个项目连续提问时，AI 会参考该项目最近的文字问答；不同项目和账号互不混用。

回复会逐步显示，生成期间可点「停止生成」。中途停止或网络中断的半截回复不会写入已完成对话历史。每次请求都可能产生上游 Token 费用；切换模型后历史上下文会继续作为文字传给新模型。

文字生图与参考图
  1. 在右侧 AI 创作助手选择中转站、生图模型、比例、画质和数量（默认1 张）。
  2. 在描述框写清楚主体、场景、风格和需要修改的内容；也可以点击 ＋ 添加参考图，或把图片拖到画布上。
  3. 点击发送或使用 Ctrl + Enter，确认后创建生成任务。
  4. 生成过程中会显示排队、运行状态和等待计时；完成后新作品会出现在画布上方，点击图片可继续修改、收藏或下载。

真实生图、图片反推和能力实测可能消耗你的中转站额度；等待动画不表示精确生成百分比。

图片反推与本地编辑

上传或选中参考图后，在助手点击「图片反推」，在反推弹窗中选择本次服务商与视觉模型，再点击「开始反推」，可把图像分析为可复用的文字描述。图片反推模型必须支持识图，反推请求可能产生费用。

点选画布图片，在操作工具中可以进入本地编辑：裁切、旋转、镜像、去白边和调整尺寸。这类本地处理在浏览器完成，不调用 AI；AI 局部重绘则需要模型支持对应接口。

备份、空间与错误排查

在顶部「画布工具」选择「导出当前项目 (.hamoki)」保存完整项目备份；需要恢复时使用「导入项目备份」。重要图片还应另行下载原图。

每个账号默认最多 1 GB 图片空间，全站预算 5 GB。空间不足时系统会自动清理该账号的旧图片，删除后无法从网站恢复，请定期备份。

生成失败时，先确认中转站地址、Key、模型 ID 和生图模式匹配，再点击左侧「查看日志」→「复制日志」，把错误发给管理员排查；日志不会展示你的 Key 和密码。

有疑问？先检查中转站设置和错误日志。
